# Appendices README

This directory contains supporting background information and calculation references for the feasibility study.

## Files

| File | Purpose |
| ---- | ------- |
| `glossary.md` | Definitions of poultry, finance, and farm operations terminology |
| `assumptions.md` | Core project assumptions used across technical and financial analysis |
| `abbreviations.md` | Expanded forms of acronyms used in the repository |
| `calculation-methodology.md` | Method used for production, cost, and profitability calculations |
| `bibliography.md` | Structured source listing and reading references |

## Purpose

These appendices help readers understand the assumptions, terminology, and methodology behind the report, making the study easier to review, validate, and update.
