# Assets README

This directory stores visual and diagrammatic assets that support the poultry farm feasibility study.

## Contents

### `images/`

Static visuals used in documentation, such as farm layout, shed design, cage systems, feed storage, and water system illustrations.

### `diagrams/`

Editable Draw.io files for workflow mapping, farm design, disease-response flow, and risk visualization.

### `charts/`

Rendered charts for egg pricing, feed cost trends, ROI comparison, cash flow, and production planning.

## Usage

Use these assets inside documentation, presentations, loan proposals, or investor decks to improve clarity and visual communication.
