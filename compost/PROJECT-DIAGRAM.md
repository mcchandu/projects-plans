| — | **Total site** | **600 m²** | **~870 m²** |

### How Materials Flow Through the Site

```
Raw Material → Shredding → Windrow → Curing → Screening → Storage → Dispatch
   (Zone 1)    (Zone 2)   (Zone 4)  (Zone 5)  (Zone 6)   (Zone 7)  (Zone 8)
```

## Diagram 3 — Step-by-Step Process Flow

```
 INPUTS: Cow dung, Paddy straw, Neem cake, Poultry litter, Leaves
                          │
                    ① RECEIVING
                  Weigh and sort materials
                          │
              ┌───────────┴───────────┐
              │                       │
         ② SHREDDING            PRE-SOAKING
         Cut to 5–8 cm         Soak straw 12–24 hrs
              │                  in dung slurry
              └───────────┬───────────┘
                          │
                   ③ BUILD WINDROW
                  Layer browns + greens
                  Set moisture 50–60%
                  Tag with date + number
                          │
                ④ ACTIVE DECOMPOSITION
                     Weeks 1–8
                  Turn every 5–7 days
                  Check temp + moisture daily
                          │
                   ⑤ CURING ZONE
                     Weeks 9–11
                 Lower pile, less turning
                  Check smell + germination
                          │
                     ⑥ SCREENING
                  Sieve through 6–8 mm mesh
                  Rejects go back to next batch
                          │
                ⑦ COVERED STORAGE
                  Keep dry, max 6 months
                          │
                     ⑧ DISPATCH
               Bulk delivery or bagged sale
```

## Diagram 4 — Batch Rotation Calendar

> Each row = one windrow. One new windrow is built every 3 days.
> Shown weekly for simplicity.

```
Windrow │ Wk1 │ Wk2 │ Wk3 │ Wk4 │ Wk5 │ Wk6 │ Wk7 │ Wk8 │ Wk9 │W10 │W11 │W12
────────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼────┼────┼────
 W-01   │ NEW │ HOT │ HOT │ ACT │ ACT │ MAT │ MAT │ CUR │ CUR │SCR │STR │    
 W-02   │     │ NEW │ HOT │ HOT │ ACT │ ACT │ MAT │ MAT │ CUR │CUR │SCR │STR
 W-03   │     │     │ NEW │ HOT │ HOT │ ACT │ ACT │ MAT │ MAT │CUR │CUR │SCR
 W-04   │     │     │     │ NEW │ HOT │ HOT │ ACT │ ACT │ MAT │MAT │CUR │CUR
```

**Stage meaning:**
- **NEW** — Built this week (4,200 kg in, moisture set)
- **HOT** — Peak heat 55–65°C, turn every 5–7 days
- **ACT** — Still active, 45–55°C, turn weekly
- **MAT** — Cooling down, 35–45°C, turn once
- **CUR** — Curing zone, check smell and germination
- **SCR** — Screening through 6–8 mm sieve
- **STR** — In storage, ready to sell

**Key timing:**
- First finished product ready → **Week 11 from Day 1**
- At full rotation → **~9,500–10,500 kg/month**
