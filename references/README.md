# References README

This directory contains supporting reference material used alongside the feasibility study.

## Files

| File | Purpose |
| ---- | ------- |
| `government-schemes.md` | Summary of relevant state and central support schemes |
| `nabard-guidelines.md` | Lending, subsidy, and appraisal reference points linked to NABARD-style evaluation |
| `vaccination-schedule.md` | Indicative vaccination planning for layer birds |
| `standard-operating-procedures.md` | Farm SOPs for routine production, hygiene, and handling |
| `emergency-response-plan.md` | Response planning for disease events, utilities failure, and operational disruptions |
| `supplier-list.md` | Reference list of equipment, feed, medicine, and infrastructure vendors |
| `useful-links.md` | Curated external links for research, compliance, and market tracking |

## Purpose

These files provide implementation support beyond the core report chapters and can be used during planning, financing, setup, and farm operations.
