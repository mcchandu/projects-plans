# Financial Model README

This directory contains spreadsheet models used to evaluate the economics of the **10,000-layer commercial poultry farm** project.

## Files

| File | Purpose |
| ---- | ------- |
| `10000-layer-capex.xlsx` | Capital investment model for sheds, cages, equipment, utilities, and setup |
| `operating-expenses.xlsx` | Monthly and annual operating expense estimates including feed, labor, power, and healthcare |
| `cashflow-5-years.xlsx` | Year-wise cash flow planning for five years |
| `roi-calculator.xlsx` | Investment return, payback, and profitability metrics |
| `sensitivity-analysis.xlsx` | Scenario analysis for egg prices, feed cost, mortality, and production variation |

## Notes

These workbooks should remain aligned with assumptions documented in the study chapters and appendices. Any changes to production volume, feed conversion, mortality, selling price, or financing terms should be updated consistently across all related files.
